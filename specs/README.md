# Living specifications

Specifications in this directory describe the supported product contract, not just one-time implementation plans. Keep the active spec, acceptance scenarios, and deployment documentation synchronized when behavior or configuration changes.

Use the repository's Spec Kit skills to clarify product requirements, plan changes, generate implementation tasks, and analyze the resulting artifacts. Treat privacy, tool permissions, and compatibility decisions as requirements.

Current product specification:

- [AI draft assistant baseline](001-ai-draft-assistant/spec.md)
- [Roundcube UI localization](002-ui-localization/spec.md)

The baseline describes the extracted implementation. Open productization and validation work remains listed in its plan and tasks; do not treat unverified compatibility or tool behavior as a guarantee.
